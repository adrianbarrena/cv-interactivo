# Qué queda (tú)

1. **Vídeos** (Fase 1): grábalos en Google Vids con `guion_videos.md` y guárdalos como (ya incluidos en `videos/`).
2. **API Key** (Fase 3): aistudio.google.com → Get API Key. Pégala solo en la web, nunca en el código.
3. **GitHub** (Fase 5): crea un repo público `cv-interactivo` y ejecuta dentro de esta carpeta:
   ```
   git init && git add . && git commit -m "feat: CV interactivo con videos y Gemini"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/cv-interactivo.git
   git push -u origin main
   ```
   Settings → Pages → Deploy from a branch → main / (root).
4. **Pruebas** (Fase 6): las 3 preguntas están como botones en el chat.
